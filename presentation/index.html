Slide 02 • Motivation

The Problem: Why DSA is Hard to Learn

Traditional learning mediums fail to bridge the cognitive divide between code syntax and memory mutation.

📖 Static Textbooks

Textbooks show static code and isolated diagrams. Students struggle to visualize temporal state transitions, loop invariants, and pointer adjustments across time.

🐛 Traditional Debuggers

IDEs step line-by-line but show raw variables, hex pointers, and array indices. They fail to convey high-level spatial topology in trees, graphs, or recursion stacks.

🎥 Pre-rendered Videos

YouTube lectures are purely passive. Students cannot test custom inputs, induce cycle traps, inspect edge cases, or adjust the pacing to their own learning speed.

🎯 The ALGOVIZ Solution

An interactive, real-time playground where every algorithm is an active simulation: live customizable graphs, step-by-step playback, synchronized line-by-line syntax highlighting, and instant visual verification.

Key Cognitive Gap: Abstract Syntax ⇄ Spatial Memory Execution Target: CS Undergrads, Bootcampers & Self-Learners
Slide 03 • Engineering

System Architecture & Tech Stack

Clean separation between algorithm logic, timeline orchestration, and declarative UI rendering.

🏛️ Architecture Pipeline
  • Pure ADT Models: GraphModel, TreeModel, and LinkedListModel manage abstract domain state cleanly outside React.
  • Timeline Engine: Pre-computes immutable step snapshots with comparing indices, active pointers, and code-line mappings.
  • Reactive View Layer: React 19 + Framer Motion consumes the current step index to render smooth 60 FPS transitions.
  • Zero State Leakage: Reversing or speeding up playback never mutates or corrupts underlying algorithm data.

Slide 06 • Deep Dive

Key Engineering Challenges Solved

Overcoming complex geometric, state management, and rendering challenges.

1. Time-Travel Step Backwards

Challenge: Traditional simulations mutate objects directly in loops, making "Undo" or stepping backwards impossible without full resets.

Solution: Built an immutable snapshot generator. Algorithms pre-calculate full execution timelines. Stepping backwards is a simple O(1) index decrement: currentStepIndex - 1.

2. Antiparallel Graph Edge Routing

Challenge: When two nodes have directed edges to each other (A ⇄ B), straight SVG lines overlap, obscuring arrows and edge weights.

Solution: Formulated quadratic Bezier curves with orthogonal control point offsets. Arcs curve gracefully away from each other with centered weight badges.

3. Dynamic Tree Collision Avoidance

Challenge: Fixed coordinate grid systems cause deep unbalanced binary trees to overlap sibling branches.

Solution: Recursive spatial partitioning calculates bottom-up bounding boxes, guaranteeing optimal horizontal spacing regardless of tree depth.

4. 60 FPS Animation Smoothness

Challenge: Rapid timer events triggered heavy React re-renders, causing visual stuttering during high-speed sorting runs.

Solution: Decoupled timer loops from the React reconciliation tree using mutable refs, GPU-accelerated CSS transforms, and memoized canvas layers.

Key Metrics: Zero Re-render Bottlenecks • Clean SVG Vector Geometry Robustness: Zero external animation library dependencies required
