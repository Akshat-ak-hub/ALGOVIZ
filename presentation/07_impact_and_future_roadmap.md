### Future Roadmap & Planned Extensions

1. **A* Search & Pathfinding Grid**:
   - 2D grid matrix visualizer with interactive wall drawing, heuristic comparisons (Manhattan vs. Euclidean), and maze generators (Recursive Backtracker).
2. **Dynamic Programming Matrix Visualizer**:
   - Visual 2D table fill for classic DP problems: 0/1 Knapsack, Longest Common Subsequence, and Edit Distance.
3. **User Code Sandboxing**:
   - In-browser Monaco code editor allowing users to write their own sorting/traversal algorithms and immediately see them visualized.
4. **Graph State Export & Sharing**:
   - URL-hash state serialization allowing educators to share custom graph problem sets with students via a single link.
